## 📋 About

A terminal-based car rental system that lets users manage a fleet of cars, register customers, process rentals with optional insurance, and generate daily earnings reports — all through a menu-driven interface.

> 📌 This was the **Final Project** for the subject **Introduction to Computing** — Semester 01.

## ⚙️ Features

**🚘 Car Management**
- Add, edit, remove, and view up to 5 cars
- Store registration number, model, and daily rental price

**👤 Customer Management**
- Add and edit up to 5 customers
- Store name, contact number, and rental history

**📋 Rental System**
- Rent an available car for a chosen duration
- Optional insurance add-on (+Rs. 100)
- 10% discount automatically applied for rentals over 7 days
- Total cost calculated and displayed instantly

**📊 Report Generation**
- View total daily earnings
- See which cars are currently rented out

## 🚀 How to Run

### Option 1 — Any C++ Compiler
```bash
g++ car-rental.cpp -o car-rental
./car-rental
```

### Option 2 — Visual Studio

1. Create a new **Empty C++ Project**
2. Add `car-rental.cpp` to source files
3. Press **`Ctrl+F5`** to build and run

> No external libraries required — standard C++ only.
